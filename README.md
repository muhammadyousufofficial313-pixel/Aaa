# Unified Inbox for WhatsApp Business Platform

Enterprise-grade Android client for WhatsApp Business Platform & Cloud API.

## 📱 Mobile APK Download

GitHub automatically builds the standalone APK on every push:
1. Tap on **Releases** on the right side of this repository.
2. Tap on the latest release (`v1.0.0`).
3. Download **`app-debug.apk`** directly to your Android device and install it!

Alternatively, go to the **Actions** tab, tap on the latest workflow run, and download the `app-debug` artifact.
